# 专家访谈工作流

用于企业微信供应商信息整理、REDoc专家表增量维护，以及按录音顺序生成独立REDoc访谈纪要。

## 安装

先由仓库所有者授予同事访问此私有仓库的权限。同事在已具备GitHub访问权限的Codex中发送：

> 请安装 https://github.com/fxc1206/expert-interview-workflow 中的 skill；SKILL.md 位于仓库根目录。

也可以将仓库克隆到个人技能目录，目录名保持 expert-interview-workflow。更新时拉取仓库最新版本；存在本地修改时先核对差异。

## 使用

> 使用 $expert-interview-workflow。我的正式表地址是……；允许读取的供应商群是……；本次topic是……。只允许新增sheet、末端追加或填入明确空白，不覆盖已有内容。

需要处理录音时，在任务中提供录音/逐字稿文件或可访问路径，并说明对应topic和会议；上传腾讯会议转写需单独授权。

## 默认规则

- 企业微信和Hi只读，不发消息、不接受报价、不代预约。
- 正式表仅新增；已有内容和格式受保护。
- 供应商背景、职位、反馈、英文及报价保留原文，不翻译或自行换算；未提供字段留空。
- 专家信息按topic单独sheet；纪要为独立REDoc文档，按会议顺序整理，疑点和关键数字黄标并附时间点。
- 不自带实时消息接口或定时服务。应用登录、权限和Computer Use能力需在使用者设备上确认。
- 技能共享不等于进度共享；多人维护同一表应指定一个写入执行者。

## 文件

- SKILL.md：工作流入口
- pilot.md：首次配置和授权范围
- operations.md：增量归档及录音接入

此仓库不包含聊天记录、录音、实际表格地址、访问令牌或个人运行进度。仓库链接和技能本身不授予业务系统权限。
